# Algorytm Sortowania Bąbelkowego w Języku C

Projekt prezentuje implementację klasycznego algorytmu sortowania bąbelkowego (Bubble Sort) w języku C oraz zasadę działania generatora liczb pseudolosowych.

## 🚀 Zawartość projektu
*   `aplikacja/` — Główny podfolder zawierający kod źródłowy aplikacji.
    *   `sortowanie.c` — Implementacja algorytmu oraz funkcji wyświetlania danych w języku C.

## 🛠️ Instrukcja kompilacji i uruchomienia
Do uruchomienia programu wymagany jest kompilator GCC.

1. Kompilacja programu:
   ```bash
   C:\msys64\ucrt64\bin\gcc.exe aplikacja/sortowanie.c -o aplikacja/sortowanie.exe
   ```
2. Uruchomienie aplikacji:
   ```bash
   .\aplikacja\sortowanie.exe
   ```
